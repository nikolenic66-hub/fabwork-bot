# Фабрика Окон — Telegram-бот

Клиентский Telegram-бот для предварительного расчёта окон, дверей, балконных блоков и балконных рам.

## Основной UX

Конструктор использует **одно редактируемое сообщение Telegram**: выбор створок, схемы, размеров, профиля, стеклопакета и допов меняет то же сообщение. Кнопка «Назад» возвращает на предыдущий экран.

## Новая ценовая логика

### Окна и балконные блоки
- 58-й и 70-й профиль.
- Стеклопакет 24 мм — **5 500 ₽/м²**.
- Стеклопакет 32 мм — **7 000 ₽/м²**.
- Энергосберегающее покрытие i с двух сторон — **+2 000 ₽ за конструкцию**.
- Ориентировочная стоимость окон снижена примерно на **20%**.
- Цена балконного блока снижена примерно на **7 000 ₽** по базе конструкции.
- Монтаж — **17%** от базы конструкции и доп. элементов; фиксированная i-доплата и доставка в базу монтажа не входят.
- Доставка не входит в базу монтажа.
- Демонтаж включён в 17% монтажа.
- Для балконного блока стеклопакет считается по площади окна + двери.

### Стеклопакет отдельно
В конструкторе есть отдельный пункт **«Стеклопакет отдельно»**:
- 24 мм — 5 500 ₽/м²;
- 32 мм — 7 500 ₽/м²;
- i с двух сторон — +2 000 ₽;
- монтаж 17% к отдельному стеклопакету не добавляется;
- специальный замер стеклопакета — **500 ₽**; при замере москитных сеток — также **500 ₽**.

### Балконы и лоджии
Отдельного точного калькулятора для сложных балконных конструкций нет. В клиентском интерфейсе показывается ориентир:
- **70 000–200 000+ ₽**;
- окончательная стоимость зависит от размеров, формы, профиля и особенностей объекта;
- доступен **бесплатный замер**;
- также можно связаться с менеджером и отправить размеры/фото для предварительного расчёта.

П-образная балконная рама в 58-м профиле — внутренний ориентир **120 000–140 000 ₽**; конкретная цена определяется после замера.

## Что реализовано

- Главное меню: расчёт, замер, «Мой расчёт», заявки, сервис.
- Окна: 1 / 2 / 3 створки.
- Трёхсекционные схемы: `Г | ПО | Г`, `ПО | Г | ПО`, `Г | Г | Г`.
- Балконный блок: отдельные размеры окна и двери, типовые и свои размеры.
- Окно в балконном блоке: глухое, ПО или **Г | ПО**.
- Дверь балконного блока: поворотная или поворотно-откидная.
- Дверная москитная сетка для балконного блока — **5 000 ₽ независимо от размера**.
- Стеклопакет отдельно.
- «Соединительный профиль» вместо старого клиентского термина.
- «Другая конструкция» в клиентском интерфейсе.
- Откосов в проекте нет.
- Монтаж 17% включает демонтаж.
- Обычный замер окон, дверей и балконных блоков — бесплатно.
- Замер отдельного стеклопакета и москитных сеток — 500 ₽.
- В сервисе замена стеклопакета имеет выбор **СП 24 / СП 32**; цены **5 500 / 7 500 ₽/м²**; отдельный стеклопакет считается по площади.
- «Мой расчёт» хранится в SQLite и переживает перезапуск.
- Максимум 10 конструкций.
- Активная конструкция автоматически добавляется при заказе замера.
- Заявка сохраняется в БД до уведомления менеджера.
- Защита от повторной отправки.
- Цена помечается как ориентировочная.
- Деньги считаются через `Decimal`.
- База Amvera — `/data/bot.db`.

## Деплой на FadeHost

Репозиторий подготовлен для запуска из GitHub. FadeHost определяет Python по `requirements.txt`, а `main.py` является точкой входа. Для aiogram 3 подходит polling — отдельный домен и webhook не нужны.

В переменных окружения на стороне FadeHost задайте:

```text
BOT_TOKEN=<токен от BotFather>
MANAGER_CHAT_ID=<ID чата менеджера>
DATABASE_PATH=/data/bot.db
LOG_LEVEL=INFO
```

`BOT_TOKEN` в GitHub не добавлять. Значение вводится только в панели хостинга. Каталог `/data` используется для сохранения SQLite-базы между перезапусками.

Для запуска достаточно выбрать GitHub-репозиторий, оставить Python/автоопределение, а команду запуска — `python main.py` (если панель не определит её автоматически).

## Запуск

```bash
pip install -r requirements.txt
python main.py
```

Переменные окружения — в `.env.example`.
